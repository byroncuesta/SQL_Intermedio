## Configuración
Copie el código que se encuentra dentro de los archivos .sql ubicado en las carpetas, péguelo en una Query tool dentro del PgAdmin de Postgres. (Estos archivos contienen el código necesario para crear y poblar el esquema y las tablas utilizadas en la aplicación SQL Intermedio)
